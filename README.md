# JAPAN GRADUATION TRIP 2027

2027년 1~2월 일본 졸업여행을 계획하는 한국어 정적 웹앱. 18개 추천 코스와 66개 도시·지역, 47개 도도부현 지도를 포함합니다. 검색·비교에서 후보를 좁히고 일정과 인원별 경비를 편집할 수 있습니다.

## 실행

- Windows에서는 Python 3이 설치된 상태에서 `run.bat`를 두 번 클릭합니다. 종료할 때는 서버 창을 닫습니다.
- macOS와 Linux에서는 프로젝트 디렉터리에서 `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist` 실행 후 브라우저로 [로컬 사이트](http://127.0.0.1:8000/)를 엽니다.
- 데이터는 HTTP로 읽습니다. 브라우저에서 HTML 파일을 직접 여는 방식에는 서버 실행이 필요합니다.
- Node.js 20 이상에서 `npm test` 또는 `npm run build`로 정적 파일과 로직을 검사할 수 있습니다. 의존성 설치나 별도 번들 빌드는 필요 없습니다.

## 친구들과 사용하기

여행지 카드에서 하트나 비교 버튼을 누른 뒤 ‘나의 여행 후보’ 또는 ‘여행지 비교’로 이동합니다. 일정은 일차 및 관광지 순서를 바꾸고 메모를 적으면 자동 저장됩니다. 경비는 직접 입력하고 ‘예산 저장’을 누릅니다. 환산 시 1엔당 원화 가격을 입력합니다.

저장 데이터는 브라우저별로 관리됩니다. 후보·투표 문구와 일정은 복사해서 공유할 수 있습니다. JSON 내보내기에는 메모가 포함되므로 전송 전 내용을 확인하세요. JSON 가져오기는 확인 후 현재 브라우저 데이터를 교체합니다. 데이터 자동 동기화나 실시간 공동 투표는 제공하지 않습니다.

## 정적 호스팅 배포

`dist/`가 완성된 정적 배포물입니다. 해당 디렉터리의 **내용 전체**를 정적 호스팅의 공개 루트에 배포하세요. URL 앵커로 페이지를 나누므로 서버의 경로 재작성 설정이 필요 없습니다.

GitHub Pages의 브랜치 배포를 쓸 경우에는 게시 브랜치의 루트 또는 `docs/`에 `dist/`의 내용 전체를 넣고, Settings → Pages에서 해당 브랜치와 폴더를 선택합니다. 친구들이 접속하려면 호스팅의 접근 범위도 확인해야 합니다.

## 파일 구조

- `dist/index.html`, `app.js`, `logic.js`, `style.css` — 웹앱 소스
- `dist/data/trips.json` — 권역, 도도부현, 추천 코스, 도시, 일정, 관광지 정보
- `dist/maps/prefectures.json` — 로컬 SVG 경계 경로 데이터
- `dist/images/`, `dist/fonts/` — 로컬 삽화, 대체 이미지, 글꼴 및 라이선스
- `scripts/check.mjs` — 자동 검수
- `SOURCES.md`, `QA.md` — 출처, 검수 결과 및 미완료 범위

## 데이터 편집

`trips.json`의 `destinations`에 지역과 좌표, 소요 기간별 경비 범위, 태그, 5점 평가 및 추천 일정을 기록합니다. `price`의 미산정 값은 `null`입니다. 기온값이 없는 지역은 비워 두고, 개별 명소 설명과 공식 링크는 `attractionInfo`, `official`에 기록합니다. 새 글자에 대해 브라우저에 설치된 한글 글꼴이 대체 글꼴로 적용될 수 있습니다.
